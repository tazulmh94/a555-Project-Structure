## rangkuman
Project ini merupakan analisis  data kualitas udara di stasiun Huairou. Adapun tujuan dari project ini yaitu melihat perubahan nilai polutan khususnya PM2.5 dan PM10 setiap tahunnya. selanjutnya melakukan analisis apakah terdapat hubungan atau korelasi antara polutan PM2.5, CO, dan NO. terakhir, untuk mengetahui pada bulan apa nilai tertinggi polutan PM2.5 dan berapa nilai tertinggi polutan PM2.5.
